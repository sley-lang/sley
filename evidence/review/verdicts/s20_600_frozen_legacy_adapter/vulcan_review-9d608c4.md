- **[P2] [record]** `machineresearch/sley-2.0/machine-summary.json:3477-3478` (`retained_timeout_evidence: true`, `runtime_evidence: evidence/runtime/s20-600-legacy-smoke/`) and ADR-0018:22-23 ("Two 10-second timeouts, one 30-second timeout … are retained") — `/evidence/runtime/` is gitignored (`.gitignore:6`), and on this review host the directory holds exactly one record, a 2026-09-12 success; the three timeout records exist nowhere reachable from HEAD or this host. - **[P3] [checker]** `scripts/check_legacy_runner.py:36-119, 133-148` — token-grep only (`"shell=False"`, `"O_NOFOLLOW"`, `".extract("`, `runner.count("60_0") < 15` at `:118` accepts ≥15 and counts substrings, not enum members); `stable_error_codes: 15` and `synthetic_smoke_tests: 9` are hardcoded literals (`:147-148`) rather than `len(LegacyErrorCode)` / discovered test count; `FROZEN_CONTRACT` is imported but never reconciled against the spec's pinned values (only the sha token is grepped; size, commit, tree digest, `bin/sley` digest, counts are not) nor against the register section's `artifact_sha256`/`source_commit`/counts/`allowed_command`/`successful_version_output`; the retained-evidence directory is never read. `verify_frozen_artifact()` at `:135` binds `make quick` to the host-local absolute default path (`runner.py:35-37`): on any host without the archive the gate reports `FAIL` via `ARTIFACT_MISSING`, indistinguishable from a real identity/verification failure — it should surface `ARTIFACT_MISSING` as `BLOCKED`. - **[P3] [implementation]** `bench/legacy/runner.py:753-756, 775-778, 770` — the post-extraction `os.chmod` loops, the `stage_parent`/`scratch` mkdirs, and `TemporaryDirectory` creation sit outside any `LegacyRunnerError` translation. ## SUMMARY

Against the correct lane's six acceptance criteria the adapter is complete and correctly built: outer identity hashed on the open descriptor before parsing, private re-verified copy, manual `O_EXCL|O_NOFOLLOW` extraction confined by `relative_to`, per-file rehash at both verification and write, one internally constructed argv with an exact-path executable gate, `shell=False`/closed fds/no stdin/exact env/new session with group kill on deadline and overflow, and create-only fsynced evidence with no rewrite/delete API. Spec, ADR, README, register, `FROZEN_CONTRACT`, and the retained record agree on every pinned value at HEAD. What keeps it from PASS is not mechanism but verification and record reproducibility: 7/15 stable codes and every contamination-specific rejection branch lack a producing test, so the routine gate cannot detect a regression in half the verifier; the register's `retained_timeout_evidence: true` is unverifiable from HEAD and false on this host's filesystem; and the checker validates string tokens and hardcoded literals rather than reconciling `LegacyErrorCode`, `FROZEN_CONTRACT`, spec, and register, while conflating absent-artifact with verification failure.

**Required for PASS:** (1) add a synthetic negative test producing each of the seven unexercised codes and each listed contamination path, asserting the code symbol; (2) either commit a digest index of the retained timeout records (filename, sha256, status, duration) or amend the register/ADR to state the timeout evidence is host-local and not reproducible from the tree; (3) have the checker derive counts from `LegacyErrorCode` and the discovered test set, reconcile `FROZEN_CONTRACT` against the spec's pinned values and the register section, and report `BLOCKED` (distinct result) on `ARTIFACT_MISSING`; (4) bound the post-kill drain with a secondary deadline, classify `wait` timeout as timeout, and wrap the chmod/mkdir/tempdir paths so every attempt reaches the evidence path. Item (4) is P3 and would not alone block PASS.
