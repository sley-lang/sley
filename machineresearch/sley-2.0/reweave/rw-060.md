## 7. Finding RW060-F1 (confirmed by both reviewers; repaired in
##    slice 2 below, not deferred)

P7 (`validate_candidate_bytes` phase 7) judged each function unit with
**unit-scoped** parameters (`parameters: &unit.parameters`), but
`CallDirect` signature resolution (`function_signature`) needs the
**callee's** parameter types. Any candidate containing a call to a
callee *with parameters* therefore failed P7 with
`VM_LOWER_IMMEDIATE_MISMATCH` (26003) even though `lower_function` /
`execute_function` accept the identical program (their judgment context
uses the full root inventories). Nullary callees were unaffected.
Lowering accepts-what-judgment-accepts (S20-360 §3.1 invariant) was
violated across the two call sites: P7 starved the context that
lowering feeds. Both reviewers confirmed the analysis and ruled
fix-now (Ariadne: do not defer an explicit validator/lowerer invariant
violation; Nabu: internal semantic-context repair, not a host-ABI
change, no RW-070 impact).
