gate-refused out-of-bootstrap program. The dependency section enforces its
byte ceiling incrementally during encoding (refusal before unbounded
growth). The legacy `execute_loaded_image`/`ApprovedImage` path is
preserved unchanged for the closed RW-070 evidence and marked superseded

## 5. AR-05: compiler-scale composition evidence (provisional early-R3)

Measured on this host (not release performance evidence):

- A. Branching work queue: diamond-plus-cycle graph (0->[1,2], 1->[3],
  2->[3], 3->[1]), fan-out 2, explicit queue + visited set, sorted
  neighbors, BFS order `[0,1,2,3]`, cycle 3->1 not re-enqueued. Frontier
  decisions execute through the repaired boundary (`AND(NOT visited,
  discovered)`, 2 bootstrap ops). Totals: 5 edges / 10 step executions,
  10 instructions, 15 fuel, peak 228 units, 2 ms.
- B. Real image emission: hand-built 3-block `CondBranch` program
  (`AND`/`NOT`/`AND` across branches — no copied byte sequence), lowered
  twice to byte-identical 328 bytes, `load_image` round trip (3 blocks),
  image digest `b9cd88a3...`, executed through the repaired boundary
  (true->true, false->false), 0 ms-scale.
- C. Mixed workload: constant lookup + traversal step + byte emission +
  `ValueHash` hashing + over-bound refusal in one bounded run: 5
  instructions, 9 fuel, peak 228 units, 356 copied bytes, 172 emitted
  bytes, 32-byte digest out, 2 ms; over-1 MiB hashing refuses instead of
  truncating.

Provisional early-R3 representation/resource budget (from this evidence):
per-step ceiling 10k instructions / 100k fuel / 1M value units (unchanged
reference budgets — workloads use <0.2% of fuel, <0.03% of value units);
package envelope ceiling 64 MiB total with 8 MiB constants / 8 MiB layouts
/ 1 MiB imports sub-budgets (sections inside the envelope, not additions);
raw-hash ceiling 1 MiB (bridge-symmetric). Explicit evaluations: (a) 1 MiB
Bytes bridge vs 64 MiB image limit — no workload needed more than 356
copied bytes in one call; larger compiler preimages chunk through repeated
1 MiB bridge/hash calls under the driver (RW-120), so neither limit moves;
(b) PSH1 element-type restrictions — the single-push-row-per-inventory
freeze held for every workload (all pushes `UInt(8)`/unit-typed); multi-
type closures need a new admission, not a second row; (c) quadratic vector
cloning — `VectorSet`-style full clones were not exercised past tiny
vectors; any future large-vector workload must measure clone chains
explicitly before claiming a capacity gap (a performance problem is not a
semantic gap). No limit was increased and no primitive added on the basis
of these workloads.
